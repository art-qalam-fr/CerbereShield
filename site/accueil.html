Cerbere Security Shield

Une suite de sécurité Windows gratuite, open source et 100 % locale — surveillance des ports réseau, blocage des pubs et trackers, contrôle parental, durcissement du pare-feu et détection d'intrusion. Sans télémétrie, sans cloud, sans compte.

⬇  Télécharger pour Windows Code source

Version bêta — Windows 10 / 11 (64 bits)

Ce que Cerbere surveille pour vous

Un seul tableau de bord, visible dans le navigateur ou en application de bureau, qui garde un œil sur ce qui entre et sort de votre machine.

🔌

Ports réseau en temps réel

Inventaire continu des ports en écoute, classification critique / inattendu / protégé, score de risque global et recommandations de durcissement du pare-feu.

🚫

Blocage pubs & trackers

Filtrage DNS local basé sur les listes EasyList, AdGuard, OISD et HaGeZi — mises à jour automatiques, statistiques de blocage en direct.

👨‍👧

Contrôle parental

Filtrage par catégories et par domaine, créneaux horaires, quotas journaliers et journal des accès — protégé par un PIN indépendant.

🔥

Durcissement pare-feu

Audit des ports exposés, plan de durcissement généré automatiquement et application des règles de pare-feu Windows recommandées.

🚨

Détection d'intrusion

Détection des scans de ports et des tentatives de force brute, bannissement automatique des adresses IP hostiles, liste blanche gérable.

🔒

Verrou applicatif

Le tableau de bord peut être verrouillé par votre mot de passe de session Windows ou un mot de passe dédié — les réglages sensibles restent protégés.

Local par conception

Cerbere tourne entièrement sur votre machine. Vos données ne partent nulle part.

  • Aucune télémétrie, aucun tracking, aucun compte à créer
  • Aucune donnée envoyée vers un serveur distant
  • Code source ouvert et auditable sous licence MIT
  • Interface traduite en français, anglais, allemand et espagnol
  • Fonctionne dans le navigateur ou en application de bureau dédiée
  • Icône de zone de notification : la protection continue en arrière-plan

Installation en trois étapes

Un installeur, un clic, et la protection démarre.

  1. Téléchargez l'installeur via le bouton ci-dessus ou la page Releases GitHub — fichier CerbereShield_Setup.exe.
  2. Lancez l'installation — Windows peut afficher un avertissement SmartScreen pendant la phase bêta : Informations complémentaires → Exécuter quand même. Détails dans la page Avertissements.
  3. Le tableau de bord s'ouvre dans votre navigateur ou en application de bureau — la surveillance des ports et le filtrage sont actifs immédiatement.
Version bêta. Cerbere Security Shield est en test ouvert : l'application est fonctionnelle et utilisée au quotidien, mais peut encore contenir des imperfections. Les binaires sont signés avec un certificat de test en attendant la validation de notre signature de confiance — Windows peut donc afficher un avertissement.
