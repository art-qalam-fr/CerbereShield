# payment_domains.txt — Liste curée de domaines de paiement en ligne
# ============================================================================
# Projet : Cerbere Security Shield — module parental_control (contrôle domestique)
#
# But : empêcher qu'un enfant (ou un logiciel indésirable) utilise la carte
#       bancaire des parents en ligne — processeurs de paiement, pages 3-D
#       Secure, banques, néobanques, crédit/BNPL et cartes prépayées.
#
# Provenance : liste curée MANUELLEMENT pour le projet, domaines vérifiés sur
#              les documentations officielles des PSP/banques (recherche web).
#              AUCUNE liste externe n'est importée — pas de licence tierce,
#              contenu 100 % projet, versionné dans le dépôt.
# Dernière mise à jour : 2026-09-21
#
# ⚠ RAPPEL — le blocage DNS est BINAIRE :
#   chaque entrée bloque le domaine ET tous ses sous-domaines (matching par
#   suffixe). « Consulter sans payer » est impossible : ex. paypal.com bloque
#   aussi bien le site d'information que la page de paiement.
#
# Format : un domaine par ligne (minuscules, sans schéma ni chemin).
#          Lignes vides et commentaires (#) ignorés par le chargeur.
# ============================================================================
