# ============================================================================
# vpn_domains.txt — Liste curée de domaines de fournisseurs VPN grand public
# ============================================================================
# Projet : Cerbere Security Shield — module parental_control (contrôle domestique)
#
# But : empêcher le téléchargement, l'inscription et la configuration d'un VPN
#       grand public utilisable pour contourner le filtrage DNS local — le
#       tunnel VPN chiffre et déporte la résolution DNS chez le fournisseur.
#
# Provenance : liste curée MANUELLEMENT pour le projet, domaines vérifiés sur
#              les sites officiels des fournisseurs VPN et leurs documentations
#              (recherche web). AUCUNE liste externe n'est importée — pas de
#              licence tierce, contenu 100 % projet, versionné dans le dépôt.
# Dernière mise à jour : 2026-09-21
#
# ⚠ LIMITATION — bloquer le DOMAINE d'un VPN ne bloque PAS un client VPN
#   déjà installé : une fois le tunnel établi, le trafic (dont le DNS) passe
#   dans le tunnel chiffré vers des IP de serveurs, sans toucher ces domaines.
#   Cette liste empêche l'acquisition/initiation, pas un tunnel existant.
#
# ⚠ RAPPEL — le blocage DNS est BINAIRE :
#   chaque entrée bloque le domaine ET tous ses sous-domaines (matching par
#   suffixe). Ex. proton.me bloque aussi mail.proton.me (Proton Mail).
#
# Format : un domaine par ligne (minuscules, sans schéma ni chemin).
#          Lignes vides et commentaires (#) ignorés par le chargeur.
# ============================================================================

# ----------------------------------------------------------------------------
# CAS PARTICULIERS DOCUMENTÉS
# ----------------------------------------------------------------------------
# - VPN intégrés aux antivirus (Norton, Kaspersky, Avast/AVG, McAfee,
#   Bitdefender) NON listés : bloquer le domaine de l'éditeur casserait les
#   mises à jour de l'antivirus — à traiter au cas par cas par sous-domaine.
# - tailscale.com / zerotier.com : la sortie Internet n'existe que si un
#   « exit node » est configuré — bloqués car la mise en place se fait via
#   le domaine (coordination/login tailscale.com).
# - torproject.org : Tor n'utilise pas le DNS local, mais le téléchargement
#   du navigateur passe par le domaine — d'où sa présence ici.
# - Les domaines d'infrastructure (cgvpn.info, goldenfrog.com, nordcdn.com)
#   bloquent aussi les appels API des clients → perturbent l'activation.
